# Project Summary
Repro Suite is a bilingual hub for discovering and opening five research-reproducibility tools. Its static pages describe each tool and its intended audience, with links that open in new tabs. The hub also includes language and theme controls, plus a blog. It does not require a database or API keys.

# Project Module Description
- **Hub page:** Presents the tools, a hero section with “Explore the tools” and “Watch the demo” actions, and a credit line: “Built on Atoms by Group 1, Tsinghua SIGS AIID capstone.” The demo action opens Paper Repro Agent.
- **Tool directory:** Five cards with English and Chinese descriptions and audience labels:
  - **Paper Repro Agent:** Checks whether a paper’s headline number reproduces by reading, setting tolerance, writing code, rerunning clean, and auditing. For researchers and reviewers.
  - **Repro Lite:** Checks one claim in about 40 seconds using an agent that runs Python in the browser. For students and readers seeking a quick check.
  - **Reading Companion:** Reads arXiv papers with users, saves quoted notes, cites claims, and marks what it could not verify. For anyone reading papers outside their field.
  - **IndexBoard:** Turns results or a sentence into a leaderboard with intervals and ties; AI can build the board and retrieve live model data. For evaluation teams and anyone comparing models.
  - **Repro Desk:** Offers a human-checked reproduction request for a paper as a free pilot. For labs and authors.
- **Language and theme controls:** English/Chinese and light/dark toggles; preferences are remembered between visits.
- **Blog:** Blog index and article pages, Markdown rendering, and prerendering support.
- **Shared UI:** Reusable components and hooks for navigation, forms, dialogs, notifications, and responsive layouts.

# File Description Inventory
- `src/lib/content.ts`: Static tool descriptions, audience labels, and bilingual content.
- `src/pages/Index.tsx`: Hub hero, credit line, tool cards, language and theme controls.
- `src/App.tsx`, `src/main.tsx`: Application routing and entry point.
- `src/index.css`, `src/App.css`: Global design tokens and application styles.
- `src/pages/blog/`, `src/components/blog/`, `src/blog-routes.tsx`: Blog pages, article rendering, and routes.
- `prerender/`: Blog prerendering, sitemap generation, and helpers.
- `src/components/ui/`: Reusable interface components.
- `src/lib/`: Content, configuration, blog, API, and utility helpers.
- `plugins/`: Development safeguards and tests.
- Root configuration files: Build, lint, styling, type-checking, and browser-test configuration.

# Technology Stack
- React and TypeScript

- Tailwind CSS and PostCSS
- Reusable component-based UI
- Playwright and ESLint
- Static site content; no database or API keys required

# Usage
From the frontend directory, install dependencies and start the development server:
```bash
cd app/frontend
npm install
npm run dev
```

Run checks and build:
```bash
npm run lint
npm run build
```
