# Project Summary
Repro Suite is a bilingual product hub for researchers who want to understand and verify AI research papers. It focuses on two main products: Paper Explainer, which creates short narrated paper videos, and Paper Repro Agent, which re-runs experiments and reports whether results hold. The hub also links to four supporting tools and a research benchmark.

# Project Module Description
- **Responsive navigation:** A 248px sidebar groups links into Main products, Supporting tools, and Research. On screens under 900px, it becomes a drawer opened from a slim top bar. External app links open in new tabs.
- **Hero and primary actions:** Introduces the suite and provides direct actions to explain or check a paper.
- **Paper Explainer card:** Shows the newest English video from the public video feed, starting at 2 seconds, and displays the number of videos returned by the feed. If the feed is unavailable, it falls back to the Paper Explainer screenshot and a note.
- **Paper Repro Agent card:** Presents the product screenshot, workflow description, and reproduction statistics.
- **Workflow diagram:** Shows Paper → Explainer → Repro Agent → Benchmark.
- **Supporting tools:** Links to Repro Lite, Reading Companion, IndexBoard, and Repro Desk with descriptions and screenshots.
- **Language and theme controls:** English/Chinese switch and light/dark toggle. Light mode is the default; theme preference is stored under `repro.theme2`.
- **Footer:** Identifies the Group 1 Tsinghua SIGS AIID capstone and partners DeepWisdom and StepFun, with links to all seven apps.

# File Description Inventory
- `src/pages/Index.tsx`: Main hub layout, sidebar/drawer, product cards, workflow diagram, supporting tools, and footer.
- `src/lib/content.ts`: Bilingual hub copy, product descriptions, and app links.
- `src/index.css` and `src/App.css`: Theme tokens, typography, responsive layout, and application styling.
- `public/shots/`: Existing optimized product screenshots used by the hub.
- `src/App.tsx`, `src/main.tsx`: Application routing and entry point.
- `src/pages/blog/`, `src/components/blog/`, `src/blog-routes.tsx`: Blog pages, article rendering, and routes.
- `prerender/`: Blog prerendering and sitemap utilities.
- `src/components/ui/`, `src/hooks/`, `src/lib/`: Shared UI, hooks, API, configuration, content, and utility code.
- `scripts/capture_shots.py`: Product screenshot capture and optimization.
- `plugins/` and root configuration files: Development safeguards and build, lint, styling, type-checking, and browser-test configuration.
- `src/components/site/BrowserFrame.tsx`: Removed; the redesigned hub no longer uses the browser-frame component.

# Technology Stack
- React and TypeScript
- Vite
- Tailwind CSS and PostCSS
- Inter, Noto Sans SC, and JetBrains Mono typography
- Lucide icons
- WebP screenshots and HTML video
- Public Supabase video-feed endpoint for the latest Paper Explainer video and feed count
- Playwright and ESLint
- Python Playwright and Pillow for screenshot capture

# Usage
From the frontend directory, install dependencies and start the development server:

```bash
cd app/frontend
npm install
npm run dev
```

Run lint and build checks:

```bash
npm run lint
npm run build
```

To refresh screenshots, run `scripts/capture_shots.py`; screenshot capture requires Python Playwright and Pillow.
