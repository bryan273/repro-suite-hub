# Project Summary
Repro Suite is a bilingual product hub for researchers exploring and verifying AI papers. Its main products are Paper Explainer, which presents papers through narrated videos, and Paper Repro Agent, which reruns experiments and reports whether results hold. The hub also introduces four supporting tools and a research benchmark.

# Project Module Description
- **Navigation and controls:** Responsive sidebar and mobile drawer organize products, tools, and research. English/Chinese and light/dark controls are available; the theme preference is stored as `repro.theme2`.
- **Hero and workflow:** Introduces the suite, provides actions to explain or check a paper, and diagrams the Paper → Explainer → Repro Agent → Benchmark workflow.
- **Paper Explainer:** Displays the latest video and feed count. English pages use `videos.en`; Chinese pages use `videos.zh`. It switches tracks with the page language and falls back to the other track if needed. If the feed is unavailable, it shows a screenshot and note.
- **Paper Repro Agent:** Presents the product and benchmark screenshots, workflow description, and reproduction statistics.
- **Supporting tools:** Links to Repro Lite, Reading Companion, IndexBoard, and Repro Desk with descriptions and eagerly loaded screenshots.
- **Footer:** Identifies the Group 1 Tsinghua SIGS AIID capstone and partners DeepWisdom and StepFun, with links to all seven apps.

# File Description Inventory
- `src/pages/Index.tsx`: Hub layout, navigation, product cards, workflow, supporting tools, and footer; handles language-specific video selection and eager loading of tool images.
- `src/lib/content.ts`: Bilingual hub copy, product descriptions, and app links.
- `src/index.css` and `src/App.css`: Theme tokens, typography, responsive layout, and application styling.
- `public/shots/`: Optimized screenshots for Paper Repro Agent, its benchmark, and supporting tools; refreshed to reflect the current app designs.
- `scripts/capture_shots.py`: Captures and optimizes product screenshots.
- `src/App.tsx`, `src/main.tsx`: Application routing and entry point.
- `src/pages/blog/`, `src/components/blog/`, `src/blog-routes.tsx`: Blog pages, article rendering, and routes.
- `prerender/`: Blog prerendering and sitemap utilities.
- `src/components/ui/`, `src/hooks/`, `src/lib/`: Shared UI, hooks, API, configuration, content, and utility code.
- `plugins/` and root configuration files: Development safeguards and build, lint, styling, type-checking, and browser-test configuration.

# Technology Stack
- React and TypeScript
- Vite
- Tailwind CSS and PostCSS
- Inter, Noto Sans SC, and JetBrains Mono typography
- Lucide icons
- WebP screenshots and HTML video
- Public Supabase video-feed endpoint
- Playwright and ESLint
- Python Playwright and Pillow for screenshot capture

# Usage
From the frontend directory, install dependencies and start the development server:

```bash
cd app/frontend
npm install
npm run dev
```

Run lint and build checks:

```bash
npm run lint
npm run build
```

To refresh screenshots, run `scripts/capture_shots.py`; screenshot capture requires Python Playwright and Pillow.
