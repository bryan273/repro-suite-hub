# Project Summary
Repro Suite is a bilingual company-style hub that helps visitors discover and open five research-reproducibility tools from one place. It presents the tools with concise descriptions and audience information, with links opening in new tabs. The site uses static content and does not require a database or API keys.

# Project Module Description
- **Hub page:** Hero message, supporting text, “Explore the tools” and “Watch the demo” actions, plus five tool cards. The demo action currently opens Paper Repro Agent.
- **Tool directory:** Links to Paper Repro Agent, Repro Lite, Reading Companion, IndexBoard, and Repro Desk. Each card includes a name, short description, intended audience, and Open button.
- **Language and theme controls:** English/Chinese toggle and light/dark mode toggle. Preferences are remembered between visits.
- **Blog pages:** Blog index and article pages, Markdown article rendering, and prerendering utilities are included.
- **UI components:** Reusable interface components and hooks, including buttons, cards, dialogs, navigation, forms, toasts, and responsive layout utilities.

# File Description Inventory
- `src/pages/Index.tsx`: Main hub page, tool listings, language and theme controls.
- `src/App.tsx`, `src/main.tsx`: Application setup and rendering entry point.
- `src/index.css`, `src/App.css`: Global design tokens and application styles.
- `src/lib/content.ts`, `src/lib/config.ts`: Static content and configuration support.
- `src/pages/blog/`, `src/components/blog/`, `src/blog-routes.tsx`: Blog presentation and routing.
- `prerender/`: Blog route prerendering and sitemap support.
- `src/components/ui/`: Shared interface building blocks.
- `plugins/`: Development safeguards and their tests.
- Root configuration files: Build, lint, styling, type-checking, and browser-test configuration.

# Technology Stack
- React and TypeScript
- Vite
- Tailwind CSS and PostCSS
- Reusable component-based UI
- Playwright and ESLint
- Static site content; no database or API keys required

# Usage
From the frontend directory:
```bash
cd app/frontend
npm install
npm run dev
```

To check or build the project:
```bash
npm run lint
npm run build
```
